
# WeSplit

A simple bill-splitting app built with SwiftUI. WeSplit calculates how much each person needs to pay based on the bill amount, number of people, and selected tip percentage.
# Features
Enter a bill amount
Select the number of people
Choose a tip percentage
Automatically calculate the amount each person needs to pay
Currency formatting based on the device's locale
Decimal keyboard for entering the bill amount
"Done" button to dismiss the keyboard
# Built With
Swift
SwiftUI
Xcode
